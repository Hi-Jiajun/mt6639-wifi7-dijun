# MT6639 / Filogic 380 官方能力核对（2026-10-22）


## 结论（决定计划走向）

1. **保留 6GHz 研究目标，将注册与真实收发分开验收。** 小米官方参数页公开列出 2.4/5GHz 和 MLO；这为日用功能提供明确基线，但没有证实本机 6GHz 能力。适用频段与测试条件应在发射试验前核实，不能用未公开支持来否定硬件研究目标。
2. **本轮未找到 MediaTek 对本机 MT6639 与 Filogic 380 的明确料号映射。** 其它 MT7927 模组的蓝牙 variant 也叫 0x6639，只能作为旁证，不能推翻本机 PCI 14c3:6639 和 wlan_drv_gen4m_eap_6639 的实际记录，也不能据此认定手机 Wi-Fi 是 MT7925。
3. **QM45197 / QM42195 官方页面没有公开频段数据，不能用它们证明 6GHz 射频链存在。** 6GHz 必须按"监管准入 → 扫描 → 关联 → 吞吐"四层分别取证；FEM 覆盖某频段不等于整机天线、滤波、校准和型号核准已就绪。

## 取证边界

只读公开文档；未操作手机、未用 adb、未跑 root、未改模块。"官方"指 MediaTek / 小米 / Qorvo / 工信部 / 国家无线电办公室原文页；拆解与内核补丁只作侧证。官方没写的，一律写"未知"，不用营销规格反推本机功能。

## 1. MT6639 与 Filogic 380 是否同一颗

**MediaTek 官方 Filogic 380 页面没有出现 `MT6639` 这个型号**，只给产品名与规格，不给 part number：

> "Single-chip Wi-Fi 7 and Bluetooth 5.4 Client Combo Solution"
> 规格表：`Wi-Fi 7 (a/b/g/n/ac/ax/be)`、`2.4GHz, 5GHz, 6GHz`、`dual-band, dual-concurrent: 2x2 + 2x2`、`Up to 6.5Gbps`
> https://www.mediatek.com/products/broadband-wifi/mediatek-filogic-380

侧证一（供应链拆解）：Counterpoint 对小米 15S Pro 的拆解经集微网转述，明确写"WiFi/蓝牙模块是 `MT66398BEW`"。

> "联发科提供了基带模块T800 MT6980W、WiFi/蓝牙模块是MT66398BEW、射频收发器MT6195W和电源管理芯片"
> https://www.sohu.com/a/905885021_166680

侧证二（Linux 内核补丁）：MT7927 被明确标为 Filogic 380，蓝牙子系统 hardware variant 为 `0x6639`。

> "This series adds Bluetooth support for the MediaTek MT7927 (Filogic 380) combo WiFi 7 + BT 5.4 module. The BT subsystem uses hardware variant 0x6639 and connects via USB."
> https://lwn.net/Articles/1064782

侧证三（Linaro 工程博客）：同一模块内是两颗芯片，MT6639 是蓝牙控制器，Wi-Fi 硬件是 MT7925-based。

> "The module contains two distinct chips - a Bluetooth controller (MT6639) connected via USB and WiFi hardware (MT7925-based) connected via PCIe."
> https://www.linaro.org/blog/from-replace-it-with-intel-to-upstream-bringing-mediatek-bluetooth-wifi-7-to-linux

**判定：** 这些资料讨论的对象并不相同，不能拼接成手机料号映射已证实。手机拆解是一个供应链线索，MT7927 文档是另一个产品的线索；两个数字相同不证明同一芯片角色。本机仍以已经读取的 PCI 14c3:6639、私有 WLAN 驱动和配套固件为准，Filogic 380 的规格只用作待核对候选能力。

## 2. Filogic 380 官方能力（芯片级，不等于本机）

| 项目 | 官方写法 | 对本机的含义 |
| --- | --- | --- |
| 标准 | `Wi-Fi 7 (a/b/g/n/ac/ax/be)` | 支持 802.11be，向下兼容 |
| 频段 | `2.4GHz, 5GHz, 6GHz` | 芯片设计覆盖三频，整机可售频段由监管与 BOM 决定 |
| 天线/流数 | `dual-band, dual-concurrent: 2x2 + 2x2` | 两路 2x2，可双频并发；**不是三频同时**，也不是 4x4 |
| 峰值 | `Up to 6.5Gbps` | 芯片级两链路合计的营销峰值，不是单链路或现网实测 |
| 带宽 | `up to 320MHz BW` | 320MHz 需要 6GHz 连续频谱；5GHz 拿不到 |
| 调制/多链路 | `4096-QAM`、`MLO`、`MRU` | Wi-Fi 7 能力；实际 MCS 受 SNR/EVM 限制 |
| 蓝牙 | `5.4, LE Audio`（规格表） | 页面标题/特性段仍写 5.3，属官方页面自相矛盾，以规格表 5.4 为准 |
| 接口 | `PCI-Express 4.0 or USB 3.0` | 手机端走 PCIe 还是 USB 需看原理图/枚举 |
| 角色 | `Client Combo Solution` | 官方定位是客户端（STA）；**官方未声明 AP 能力** |

官方页面另有一处笔误：概述写 "360MHz bandwidth support"，规格表写 "up to 320MHz BW"。以 320MHz 为准。

## 3. 本机官方口径（小米 15S Pro）

小米中国官网参数页原文：

> "WLAN 协议：Wi-Fi 7，Wi-Fi 6，Wi-Fi 5，Wi-Fi 4 以及 802.11a/b/g"
> "WLAN 频率：2.4G Wi-Fi|5G Wi-Fi"
> "支持MLO，支持2x2 MIMO，Wi-Fi Direct，Miracast，2.4G、5G双路并发"
> "蓝牙：Bluetooth 5.4，Dual-Bluetooth"
> https://www.mi.com/prod/xiaomi-15s-pro/specs

**已证实：** 本机公开卖点是 2.4/5GHz、2x2、双路并发、MLO、BT 5.4。
**未证实：** 6GHz、320MHz、三频并发、4096-QAM、AP/热点具体能力——官方参数页均未写。芯片有 6GHz 能力，不等于这台机器开放了 6GHz。

## 4. 6GHz 在中国的监管现实

工信部第 62 号令《中华人民共和国无线电频率划分规定》（2023-07-01 施行）：

> "率先在全球将6425-7125MHz全部或部分频段划分用于IMT(国际移动通信，含5G/6G）系统"
> https://www.miit.gov.cn/xwdt/gxdt/sjdt/art/2023/art_ba4e3b3d237f459fa501688ee859dfa3.html

国家无线电办公室《采用 IEEE 802.11be 技术标准的无线局域网设备型号核准技术要求及测试方法》（2023-11-11）：

> "工作频率范围：2400-2483.5MHz，5150-5350MHz 以及 5725-5850MHz。"
> https://gxt.hunan.gov.cn/gxt/wxd_ycl/w_bszn_ycl/zcfg_ycl/202312/t20231221_32531702.html

**证据边界：** 上述 2023 年材料没有为中国版手机的 6GHz WLAN 发射提供依据。它们不构成完整的 2026 年法规更新审计，也不能用于推断射频硬件不存在。实际发射试验前按所在地区、整机及测试场景核实适用条件；离线驱动分析、能力来源追踪继续进行。Wi-Fi 联盟地图可作地区线索，不能替代正式文件：https://www.wi-fi.org/countries-enabling-wi-fi-in-6-ghz-wi-fi-6e

## 5. 6GHz 的四层验收，别混成一层

| 层 | 要证明什么 | 典型证据 | 常见误判 |
| --- | --- | --- | --- |
| L0 监管/型号核准 | 该频段允许发射，整机拿到核准 | SRRC 证书、频段列表、功率限值 | 芯片支持 6GHz 就以为能开 |
| L1 扫描 | 驱动/regdb 暴露 6GHz 信道，能被动扫描并发现 AP | `iw phy` 频段与 flags、scan dump、PSC/RNR 行为 | 能看到信道就以为能连 |
| L2 关联 | 能与 6GHz AP 完成认证/关联和适用安全握手；MLO 单独验收 | 双端 assoc 日志、握手及链路状态 | 扫描到 SSID 就以为关联成功 |
| L3 吞吐 | 320MHz/4096-QAM/2x2 在真实 RF 下跑出稳定速率 | iperf3、MCS/带宽/空间流、EVM/热降频记录 | 关联成功就以为能力达标 |

每一层都可以独立失败；L1 通过不代表 L2 通过，L2 通过也不代表 L3 达标。

## 6. Qorvo FEM：QM45197 / QM42195

两颗料在 Qorvo 官方商店都有产品页，但**都没有公开规格**，datasheet 需申请：

> QM45197："Status: Standard | Datasheet: Request Data Sheet"，规格区 "No Content Available"
> https://store.qorvo.com/products/detail/qm45197-qorvo/626745
> QM42195："Status: Standard | Datasheet: Request Data Sheet"，规格区 "No Content Available"
> https://store.qorvo.com/products/detail/qm42195-qorvo/818917

**判定：**
- QM45197 的工作频段：**未知**。官方无公开数据，不能用型号数字或同系列产品推断。
- QM42195 的工作频段：**未知**。商店只把它归在 `FEM, WLAN` 类目，类目不是频段。
- 因此"QM45197 覆盖 6GHz"这一前提本身**未证实**；更不能用它证明整机 6GHz 射频链存在。

可对照的是 Qorvo 确有 6GHz FEM 产品线（例如 QPF4609 标 5.925–7.125GHz、QM45655 标 5.15–7.115GHz），但那是别的料号，不能代入本机 BOM：https://www.qorvo.com/products/wireless-connectivity/wi-fi-front-end-modules

## 7. FEM 覆盖 6GHz ≠ 整机就绪

即使某颗 FEM 标称覆盖 5.925–7.125GHz，也只说明芯片本身能放大该频段。整机还差：天线与馈线（6GHz 插损更大，天线带宽/效率需单独设计）；滤波/双工（2.4/5GHz 共存、带外抑制、谐波滤波）；校准（每台机的 Tx 功率、EVM、频偏、SAR/法规功率回退）；共存（BT/Wi-Fi 2.4GHz、LTE/5G 谐波与互调）；准入（型号核准、入网要求）；软件（regdb 国家码、6GHz 信道 flags、AP 发现与 MLO 配置）。任何一项缺失，"FEM 支持 6GHz"都只是物料规格，不是用户可用的 Wi-Fi 功能。

## 8. 已证实 / 待验证清单

| 结论 | 状态 | 依据 |
| --- | --- | --- |
| Filogic 380 芯片支持 2.4/5/6GHz、2x2+2x2 DBDC、320MHz、4096-QAM、MLO、MRU、6.5Gbps | 已证实（芯片级） | MediaTek 官方页 |
| Filogic 380 官方定位为 client combo，未声明 AP | 已证实（官方措辞） | MediaTek 官方页 |
| 小米 15S Pro 中国版公开支持 2.4/5GHz、2x2、双路并发、MLO、BT5.4 | 已证实（整机级） | 小米官方参数页 |
| 小米 15S Pro 使用 MT6639 8BEW Wi-Fi/BT 模块 | 侧证 | Counterpoint/集微网拆解 |
| 本机 MT6639 与 Filogic 380 的精确对应 | 待证实 | 拆解及其它模组资料不能建立直接映射 |
| 用其它模组 BT variant 判定本机 WLAN 芯片角色 | 不成立 | 本机另有实际 PCI 和私有 WLAN 驱动记录 |
| 本机开放 6GHz | 未证实 | 小米参数页未列出；适用收发条件另外核实 |
| 本机支持 320MHz | **未证实** | 官方参数页未写；5GHz 无法提供 320MHz |
| QM45197 / QM42195 频段 | **未知** | Qorvo 官方页无数据 |

## 9. 对开发计划的直接影响

- 2.4/5GHz MLO 与并发有小米官方支持口径，可与 6GHz 研究并行验证，避免一个未知点阻塞所有功能。
- 6GHz 继续作为核心研究分支，分别记录门禁溯源、注册、扫描、关联与双向收发；尚未实测时不预设成功或失败。
- 补齐本机 Wi-Fi 设备枚举、绑定恢复、固件版本及 capability 数据；不使用另一块 MT7927 模组的资料替代本机证据。
- AP/热点能力单独验证：官方只承诺 client，SoftAP 属系统/驱动能力，需实测而不是按芯片规格推断。
- FEM 结论只作 BOM 参考，不作为功能验收依据；需要频段数据就向 Qorvo 申请 datasheet。
