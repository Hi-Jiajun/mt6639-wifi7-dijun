# 6GHz 手动国家码启用与真实关联（2026-10-27）

本 boot 实测结论只有一句：**在本 boot 已注册 Band 4 的前提下，把 regulatory country 从 CN 切到 US 并重启 Wi‑Fi，足以让 6135MHz 从 disabled 变为可用，手机能真实关联 6GHz 并跑通批量数据。** 本次走 ADB root 手动路径，**不是** v0.2.13 模块验收，也没有跨重启证据。

证据目录：`outputs/6g-manual-validate-20261027-1036/`（私有，不推送），摘要见其 `REPORT.md`。

## 实测对照

| 观测 | 切 US 前 | 切 US 后（Wi‑Fi 关/开） | 回滚后 |
| --- | --- | --- | --- |
| `cmd wifi get-country-code` | CN | US | CN |
| `iw phy` Band 4 | 60 个全 `(disabled)`，含 6135[37] | 60 个全 `(0.0 dBm)`，含 6135[37] | 60 个全 `(disabled)` |
| 全 phy disabled 数 | 60 | 3（仅 2467/2472/2484） | 73 |
| 扫描中的 6GHz BSS | 无 | `LabNet-6G` 6135 −43、`Lab_6G` 6135 −78 | 未复测 |
| 连接 | LabNet-5G 5180 / 2882Mbps | LabNet-6G **6135 / 320MHz / 5764.8Mbps** / 198.51.100.187 | LabNet-5G 5180 / 2882Mbps |
| power_save | on | on（粗测时临时关，测完复原） | on |

动作序列：`cmd wifi force-country-code enabled US` → `set-wifi-enabled disabled` → 4s → `enabled` → 12s → 复读 → `connect-network LabNet-6G wpa3`。全部 rc=0。

连通性：AP `198.51.100.242` 5/5、网关 `198.51.100.1` 3/3、`198.51.100.60` 3/3，0% 丢包。短时数据面粗测用 `toybox nc` 拉 `.60:8989` 的 100MB（104,857,999 字节含头）：省电开 1.907s，省电关 0.830s / 0.568s。这只证明链路上确有批量数据通过，**不是**吞吐下限、瓶颈归因或稳定性能验收。

回滚按实验前定的安排执行：`cmd wifi force-country-code disabled` → Wi‑Fi 关开后自动回连 LabNet-5G，country 回 CN，6135 重新 disabled，power_save 保持 on。

## 实测 / 推断分列

| 类别 | 内容 |
| --- | --- |
| 实测 | 本 boot Band 4 已注册、60 频点全 disabled；切 US + Wi‑Fi 关开后全启用，6135 可关联、可通 ICMP、可批量取数据；回滚后恢复 CN 与 5GHz |
| 实测 | `EHT PHY` 报 `320MHz in 6GHz Supported` 为真；链路 5764.8Mbps ≈ 2 流 MCS12 + 320MHz；同时 `EHT-MCS Map (BW = 320) (0x000000)` = 0 |
| 推断（未证） | `settings get global wifi_country_code` = null **只说明该键未被写入**；不能由此推出"重启必回 CN"，也不能推出国家码只有单一来源 |
| 推断（未证） | "国家码是开机可用的唯一闸门"不成立为普适结论；本 boot 只证明在该注册态下 country 足以放行，驱动/firmware/nvram 每次启动是否都这样注册 Band 4 无跨 boot 证据 |
| 不作结论 | 不把"Band 4 一直在"推广到全部历史；更早"只有两个 band"是不同注册态，两者互不覆盖 |
