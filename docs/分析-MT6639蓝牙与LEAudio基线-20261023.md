# MT6639：蓝牙与 LE Audio 只读基线

2026-10-23，dijun，boot `<UUID>`。本轮只启用一次蓝牙做能力盘点，随后恢复为关闭；没有改动 profile 属性或音频配置。

## 初始状态

蓝牙关闭。关键属性：

```text
ro.bluetooth.leaudio_offload.supported=true
persist.bluetooth.leaudio_offload.disabled=false
ro.bluetooth.a2dp_offload.supported=true
persist.bluetooth.a2dp_offload.disabled=false
```

已启用的宿主 profile 包括 A2DP source、ASHA central、AVRCP target、BAS client、GATT、HFP AG、HID device/host、MAP/OPP/PAN/PBAP 等。以下 LE Audio profile 默认关闭：

```text
bluetooth.profile.bap.unicast.client.enabled=false
bluetooth.profile.bap.broadcast.source.enabled=false
bluetooth.profile.bap.broadcast.assist.enabled=false
bluetooth.profile.csip.set_coordinator.enabled=false
bluetooth.profile.vcp.controller.enabled=false
bluetooth.profile.mcp.server.enabled=false
```

## 蓝牙开启后的只读状态

通过 `cmd bluetooth_manager enable` 开启后：

```text
State: ON
ConnectionState: STATE_DISCONNECTED
A2dpOffloadEnabled: true
LeAudio Manager: present
ISO Manager: present
iso_data_packet_length: 336
total_num_iso_data_packets: 24
supported_max_tx_octets: 251, supported_max_tx_time: 17040
supported_max_rx_octets: 251, supported_max_rx_time: 17040
le_number_supported_advertising_sets: 16
le_supported_states: 0x000003ffffffffff
```

这证明系统与控制器暴露 LE Audio/ISO 能力路径，但 profile 属性关闭时不能据此声称 BAP unicast、CSIP、VCP、broadcast 或 MCP 已可用。设备没有连接 LE Audio 外设，因此本轮无法验证 CIS/ASE、LC3、双耳同步、音量控制、广播音频或实际音质/延迟。

随后做一次显式profile生命周期实验：临时把上述6个profile属性设为true，再开启蓝牙。Host实际出现：

```text
Enabled Profile Services:
  LE_AUDIO_BROADCAST_ASSISTANT
  CSIP_SET_COORDINATOR
  MCP_SERVER
  VOLUME_CONTROL
  LE_AUDIO
  LE_AUDIO_BROADCAST

LeAudio Manager:
  GATT App ID: 51
  TBS state: No calls
  Codec location: ADSP
  Playback AF: 48000 Hz, 2 ch, 16 bit, 10 ms
  Recording AF: 16000 Hz, 2 ch, 16 bit, 10 ms
  Active Groups: none

ISO Manager:
  Available credits: 24
  Controller buffer size: 336
  CIGs: none
  BIGs (Source): none
```

这说明这些profile可在本boot内被Host加载并初始化，不再是单纯属性上报。但没有连接设备，仍没有CIS/ASE、BAP发现/配置、LC3数据流、双耳同步、音量控制、broadcast BIS或音频HAL真实播放。

实验后执行 `cmd bluetooth_manager disable`，六个profile属性全部恢复false，`settings get global bluetooth_on=0`。没有调用旧 `mt6639-full` 的模块脚本，也没有保留额外音频配置。完整dumpsys证据为 `local/evidence/t05-native-20261023/bt-leaudio-enabled-dump.txt`。

## 判定与下一步

B01 的控制器/宿主基础路径已见；B03/B04/B05 仍为未测。要晋级必须提供真实 LE Audio 耳机或可编程对端，分别记录 profile 启用、协议建立、音频路由/听音、重连与关闭回退。Broadcast 需要独立 source/assist/sink 角色证据，不能由 ISO feature 代替。
