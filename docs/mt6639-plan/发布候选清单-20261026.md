## 依赖与建议顺序

1. 先关闭当前 v0.2.6 事务，安装 v0.2.13，再通过冷/软重启窗口验证自动升级恢复；保留 v0.2.5 回滚包和升级前目录/运行态备份。
2. 在 Enforcing/KSU 环境执行 6GHz 基线、LabNet-6G checker 和 SIM/路由检查。
3. 热点 v0.1.6 与 UI 0.1.4 已安装；热点v0.2.9/UI0.2.6候选新增 app-private Settings 启动/停止桥、v3 readiness、6GHz/5GHz 固定档位、有界 C02、启动暂存清理、claimed 中断恢复及可复现打包，但必须先通过 cold boot、真实目录权限和 Enforcing 生命周期验证。
4. 补齐 `ap.key` 和 5GHz 所需的 `reconnect-2g.key` 后再做 C02/5GHz。
5. 并发门禁只作为实验资产，仅在独立短窗口中启用并 scope `android`；默认发布不应携带启用状态。

## 回滚

- KernelSU 模块：先执行 `control.sh restore`，再禁用模块；热点停止失败时保留 authority，不在同 boot 删除现场。
- UI LSPosed：关闭热点 UI 改动通过禁用模块/force-stop Settings；状态文件可由热点模块恢复为 idle。
- 并发门禁：先 `dualsta_gate.sh disarm`，再移除 request、mode 回 0、selection 恢复，最后禁用 LSPosed scope；异常时 soft reboot。
- 任何私有目录删除前先保留当前 boot 的日志、哈希和恢复结果。
