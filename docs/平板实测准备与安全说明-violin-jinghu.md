# 小米平板 7S Pro / 小米平板 7 Ultra MT6639 功能测试准备与安全说明

> 这份清单用于实机远程协同测试，预计总耗时 **45 到 60 分钟**，全部命令与操作均由我们协助完成，不需要你记忆任何专业命令。

---

## 一、招募设备与系统环境要求

1. **机型与系统**：
   - 小米平板 7S Pro（12.5 英寸，代号 `violin`）或 小米平板 7 Ultra（14 英寸，代号 `jinghu`）；
   - 官方系统 **HyperOS 3**（Android 15/16）或 **HyperOS 4**（Android 17）。
2. **Root 与注入环境（必要条件）**：
   - 已解锁 Bootloader，并已安装 **KernelSU**（包括官方 KernelSU 或基于 KernelSU 的 `u:r:ksu:s0` 分支管理器）；
   - 系统 **SELinux 为 Enforcing（强制模式）**（如有安装改 Permissive 的模块请提前关掉恢复 Enforcing）；
   - 推荐提前装好 **Zygisk Next + LSPosed**，用于体验系统设置内的 6G 频段角标与热点控制界面；
   - 测试前如果用的是冷重启掉 Root 的激活方式也没有关系，我们的测试流程支持先在同一次开机内先测功能，再视情况决定是否测重启。
3. **测试工具与周边**：
   - 一台能用数据线连平板的 **Windows / macOS / Linux 电脑**；
   - 一条可稳定传输数据的 **USB Type-C 数据线**；
   - 家里有常规 **2.4 GHz / 5 GHz Wi-Fi 路由器**，另外有一部副机/电脑用于扫热点信号即可（不强求必须拥有 Wi-Fi 6E / Wi-Fi 7 或 6 GHz 路由器；如有则可以一并测 6 GHz 关联）。

---

## 二、你的设备安全与个人隐私承诺

1. **绝不刷写或损坏系统分区**：  
   整个过程严格遵循 KernelSU 官方标准模块机制，只在内存中运行临时挂载与属性状态，**绝不对 `/odm`、`/vendor` 等原厂只读分区做任何写入修改**。
2. **防重启锁死与自动超时恢复**：  
   首次刷入时我们会默认加上 KernelSU 标准 `disable` 防自启标记，确保重启期间不自动改动任何无线配置；随后 6 GHz 试跑采用 **15 分钟有界保护**，时间一到会自动恢复原厂国别设置；随时正常重启即可 100% 回到未开启前状态。
3. **一键标准无痕卸载**：  
   测试结束后，如果你不打算继续留用，我们支持直接调用 KernelSU 标准卸载与 `pm uninstall` 清理全部测试模块与插件。
4. **隐私严格脱敏**：  
   所有巡检日志与测试报告只记录固件校验值（SHA-256）、支持信道数量、频率数字和开关状态；**不会采集或导出你家 Wi-Fi 名称、Wi-Fi 密码、MAC 地址、内网 IP 或真实设备序列号**；热点密码由你自己在命令行设置本机私有文件，全程无需向我们透露家里真实 Wi-Fi 密码。

## 三、连线前 3 分钟极简准备

在约定开始测试前，只需要花两三分钟做好以下三步即可：

1. **平板打开 USB 调试**：
   - 进入平板「设置 -> 我的设备 -> 全部参数与信息」，连续点击「OS 版本号」开启开发者选项；
   - 进入「设置 -> 更多设置 -> 开发者选项」，同时开启 **「USB 调试」** 和 **「USB 调试（安全设置）」**；
   - 用数据线将平板插到电脑，平板弹出授权框时勾选「一律允许使用这台计算机进行调试」并确定；
   - 确认 KernelSU 管理器里已经安装或可正常授予 root 权限。
2. **电脑准备远控与 ADB**：
   - 在电脑安装并登录 **网易 UU 远程**（主推，高画质且不误报风控），若没有也可安装 **ToDesk** 或 **向日葵**；
   - 如电脑以前装过 Android `platform-tools`（`adb`），可提前确认好位置；如果电脑完全没装过 `adb`，也不用提前折腾，连线后我们会把带有免 Python 运行脚本的便携工具包直接传给你使用。
3. **保持常规 Wi-Fi 连接**：
   - 正式开始时先让平板连着家里的常用 Wi-Fi（2.4 GHz 或 5 GHz 都可以）；后续需要断开路由器的纯本地热点测试会在最后一步统一再测。

一切就绪后，到约定时间把远控连接码发给我们即可，其余部署与验证步骤由我们全程操作和引导完成。
