# MT6639 完整功能解锁自测安装包清单与使用指南

> 适用设备：小米 15S Pro（`dijun`）、小米平板 7S Pro 12.5（`violin`）、小米平板 7 Ultra 14（`jinghu`）  
> 核心特点：全部采用 KernelSU 官方标准机制与内存事务挂载，**绝不修改 `/odm`、`/vendor` 等原厂只读分区**；支持任意版本拒绝时安全停用不改系统，关闭模块或卸载重启即可 100% 恢复原厂。

## 二、当前支持范围与环境要求

### 1. 机型与系统覆盖说明
- **小米平板 7S Pro（`violin`）**：当前已直接收录官方 **HyperOS 3**（Linux `6.6.118`）与 **HyperOS 4**（Linux `6.18.21`）固件哈希，全套有效。
- **小米平板 7 Ultra（`jinghu`）**：当前已直接收录官方 **HyperOS 3**（Linux `6.6.118`）与 **HyperOS 4**（Linux `6.18.21`）固件哈希，全套有效。
- **小米 15S Pro（`dijun`）**：当前最新版对 **HyperOS 4（Linux `6.18.21`）** 已收录全部 4 个模块对应哈希；**暂未收录 `dijun` HyperOS 2 / HyperOS 3 旧版系统哈希**。
- **小版本 OTA 安全门控机制**：如果手机/平板刷了尚未录入哈希表的新小版本 OTA，`mt6639-6g` / `mt6639-bt` / `mt6639-hotspot` 会严格核对原厂组件哈希并**安全拒绝启用**，不会强行挂载导致断网；此时直接刷入 `mt6639-debug-collector-v0.1.1.zip` 把 `Download` 目录里的脱敏日志发给作者即可快速补录适配。

### 2. 前置 Root 环境要求
1. **KernelSU**（含基于 KernelSU 且上下文为 `u:r:ksu:s0` 的分支管理器）。
2. **SELinux 必须处于 `Enforcing`（强制模式）**：如之前装过强制 `Permissive` 的模块请先关闭并恢复 `Enforcing`，否则蓝牙/6G/热点控制器出于安全门控会主动拒绝运行。
3. （如需 Wi-Fi `6G` 角标与设置内热点控制面板）提前装好 **Zygisk Next + LSPosed**。

## 三、手机/平板本地安装步骤（3 分钟，无需电脑）

1. **刷入 KernelSU 模块**  
   打开 KernelSU 管理器 -> 进入「模块」页 -> 点击「安装」-> 依次选择需要测试的 `.zip`（`mt6639-6g-v0.4.1.zip`、`mt6639-bt-v0.2.0.zip`、`mt6639-hotspot-v0.3.1.zip`）。  
   先不要急着点重启，等下面 APK 配置完一并重启 1 次即可。
2. **安装并勾选 LSPosed 模块（如使用 UI 面板/角标）**  
   直接像普通软件一样安装 `mt6639-ui-lsposed-0.3.0.apk` -> 打开 **LSPosed 管理器 -> 模块 -> 开启 `MT6639 Wi-Fi 6G badges` -> 在作用域里只勾选「系统设置 (`com.android.settings`)」**。
3. **正常重启 1 次**  
   重启设备让模块生效（如果用的是重启后不保留 Root 的 late-load 方案，开机进入桌面后请再点一次激活恢复 KernelSU）。

## 四、各功能使用与验证方法

### 1. Wi-Fi 6 GHz 解锁（`mt6639-6g`）
- **自动启用**：设备开机且处于联网/开启 Wi-Fi 状态后，模块会在约 20 秒内自动重启一次 Wi-Fi 完成 6 GHz 信道挂载。
- **国家码策略（兼容其他改国家码插件，且支持自定义）**：
  - 默认策略为 `auto`：如果系统原本是国内 `CN` 或 `00`，启用时自动临时切到 `US` 解锁全部 6G 信道；如果设备**本来就已经通过其他工具或海外漫游设为 `US`/`JP`/`TW`/`GB`/`DE`/`KR`/`HK`/`SG`/`AU` 等 6G 放行地区**，则自动保留你当前国家码不覆盖，只挂载 `wifi.cfg`；关闭恢复时严格还原回启用前的原始状态。
  - **手动设置国家码选项**（跨模块升级永久保存在标准数据目录 `/data/adb/mt6639-6g/country.conf`）：
    ```sh
    # 设为指定国家码（例如 JP、TW、GB、US）
    sh /data/adb/modules/mt6639-6g/bin/control.sh /data/adb/modules/mt6639-6g set-country JP
    # 或设为仅挂载配置、完全不动系统国家码（keep）
    sh /data/adb/modules/mt6639-6g/bin/control.sh /data/adb/modules/mt6639-6g set-country keep
    # 恢复默认 auto 自适应
    sh /data/adb/modules/mt6639-6g/bin/control.sh /data/adb/modules/mt6639-6g set-country auto
    ```
    设置后点一下模块的「操作」按钮开关一次（或重启）即按新国家码生效。
- **如何看是否生效**：
  - 打开 KernelSU 管理器「模块」页，观察 `MT6639 6GHz` 模块简介状态卡：显示 **`[事务运行]`** 及对应机型配置文件即已生效。
  - 如有 6 GHz / Wi-Fi 7 路由器，打开系统 Wi-Fi 列表即可看到 **`6G` 角标**并直接连接测速。
- **随时关闭/切换**：在 KernelSU 模块页点击该模块的 **「操作 / 执行」** 按钮即可一键停止事务恢复到启用前的原始国家码配置。

### 2. 蓝牙 LE Audio Host（`mt6639-bt`）
- **如何启用**：模块在开机阶段会自动执行启用。若测试过程中曾点过「操作」切换恢复/重新开启，请到控制中心**手动「关闭再重新打开」一次蓝牙开关**，新开启的 6 项 LE Audio Host Profile 即会在协议栈生效。

### 3. 原生 Wi-Fi 7 热点（`mt6639-hotspot` + 系统设置面板）
- **第一步：设置一次你自己的热点密码（必做）**  
  出于安全考虑，模块不预设任何固定密码。请使用 **MT 管理器终端 / Termux（执行 `su`）/ KernelSU 终端**，以 root 执行下面命令设置一个 8 到 63 位的纯英文数字密码（把 `MyPass1234` 换成你自己设定的密码）：
  ```sh
  mkdir -p -m 0700 /data/adb/mt6639-hotspot/private && chmod 0700 /data/adb/mt6639-hotspot /data/adb/mt6639-hotspot/private && printf 'MyPass1234\n' > /data/adb/mt6639-hotspot/private/ap.key && chmod 0600 /data/adb/mt6639-hotspot/private/ap.key
  ```
- **第二步：打开设置热点页面开测**  
  前往 **「系统设置 -> 更多连接方式 -> 个人热点」**，界面上方会出现 **MT6639 Wi-Fi 7 热点** 状态与控制按钮：
  - **情况 A（连着家里路由器测并发中继）**：手机/平板连着 2.4 GHz Wi-Fi 时可点开 **5 GHz / 80 MHz** 热点；连着 5 GHz Wi-Fi 时可点开 **2.4 GHz** 热点；连着 6 GHz 时可并发开 6 GHz/2.4 GHz 热点。
  - **情况 B（小米 15S Pro 蜂窝开 6 GHz 热点）**：断开 Wi-Fi（保持顶部 Wi-Fi 开关处于打开状态，只断开路由器连接），用手机流量可直接点开 **6 GHz 80/160/320 MHz** 热点给副机上网。
  - **情况 C（小米平板无卡纯本地直连热点 `LocalHotspotState`）**：**先断开当前连接的路由器（注意：不要关闭系统的 Wi-Fi 总开关）**，点击「本地直连 6 GHz」按钮（或若不装 UI 也可直接在 KernelSU 模块页点 `mt6639-hotspot` 的 **「操作 / 执行」** 按钮），副机搜索 **`MT6639-Native-6g-*`** 填入你刚才设定的密码即可建立高速局域网直连。
- **使用完毕关闭**：点击面板上的「停止」，或点 KernelSU `mt6639-hotspot` 的「操作」按钮即可停止并核验恢复。

## 五、问题反馈：一键导出脱敏 Debug 日志（免电脑）

如果遇到以下任一情况，不必慌张，直接导出日志发回群里/私聊即可排查：
- KernelSU 模块简介显示 `[已停止]`、`兼容门控拒绝` 或内核/哈希不匹配；
- 6 GHz 开关或热点击开启后报错、无信号、副机连不上；
- Wi-Fi 列表看不到 `6G` 角标，或个人热点页面未出现控制面板。

**导出方法（10 秒完成，无需重启）**：
1. 打开 KernelSU 管理器 -> 进入「模块」-> 安装 **`mt6639-debug-collector-v0.1.1.zip`**。
   - **刷入完成瞬间就已经自动导出一份当前日志**（安装界面最后一屏会显示保存路径）；
   - 如果之前已经安装过它，测完复现问题后只需要在模块页点击 `MT6639 Debug Log Collector` 的 **「操作 / 执行」** 按钮即可重新生成一份最新日志。
2. 打开系统 **「文件管理 -> Download（下载）文件夹」**，找到文件名类似：  
   `mt6639-debug-<机型>-<日期时间>.txt`  
   直接把这个 `.txt` 文件发回即可。

**隐私保证**：该日志仅记录机型代号、系统/内核版本、4 个原厂无线组件 SHA-256 校验值、6GHz 开放信道数、模块状态卡片与最近几条模块控制日志；**脚本层已强制过滤并擦除所有 Wi-Fi 名称（SSID）、热点密码、路由器密码、MAC 地址、IP 地址和设备真实序列号**，不会泄露个人隐私。

如果排查日志后确认需要进一步实时定位，而且你愿意配合用电脑连数据线通过 **网易 UU 远程 / ToDesk / 向日葵** 联调，我们再约时间连线。

## 六、不想留用时如何恢复纯原厂

1. 打开 KernelSU 管理器「模块」页，把装过的测试模块全部点击 **「卸载」**（包含 `mt6639-debug-collector` 也可以卸载）。
2. 如装了 `mt6639-ui-lsposed-0.3.0.apk`，像普通 App 一样卸载即可。
3. **重启一次手机/平板**，设备即 100% 回到未安装前纯原厂状态。
