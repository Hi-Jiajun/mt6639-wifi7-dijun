# SoftAP HE/EHT配置控制与5GHz最小检查

日期：2026-10-25。按“实现优先、每项最小验证、完整测试最后集中执行”的当前策略推进T08/A02。本项已完成控制入口，**5GHz/80MHz/11ax实际BSS与关闭恢复已有初证；5GHz EHT热点仍受阻**。WPA3-SAE已通过Framework的EHT配置门禁，但厂商hostapd生成文件仍缺11be参数、实际回报11ax，并出现请求5GHz却回报6135MHz的频段偏差，需独立适配。

## 新增实现

- `native/framework/WifiSoftApProfile.java`：调用本机IWifiManager读取、设置及比较完整SoftApConfiguration，Parcel独立序列化保存，避免Builder引用污染；只改HE/EHT，或额外指定5GHz及EHT兼容安全方式；原WPA2-only配置在5GHz实验档复用原密码改为WPA3-SAE，关闭时恢复原安全方式。输出不含SSID、口令或完整配置。启动使用实际`startTetheredHotspot(SoftApConfiguration, String)`签名，异步请求被接收不能作为BSS成功。
- `tools/build_softap_profile.sh`：构建反射helper的DEX，不打包原厂JAR/APK/驱动。
- `tools/softap_profile.sh TASK inspect|enable|enable-5g|restore`：三个实际层级的可恢复适配。保存目标配置、ApEHT、两个资源缓存项及两个Settings.System项，记录boot与SHA256。每个任务目录只允许一次enable，防止覆盖基线；发现完整配置或自有项冲突时拒绝覆盖。restore要求热点关闭，能记录不完整恢复。
- `tools/softap_once.sh TASK run`：单次5GHz配置/启动、8秒后接口及Framework观察、停止与配置恢复；手机独立看护90秒到期或收到结束请求时恢复。网络使用已有严格恢复组件，必要时仅选择一次原LabNet-6G。不是吞吐/兼容/长稳测试，不会宣称互联网共享可用。当前代码还要求实际SoftApInfo为5GHz且standard=8；旧两轮runner只检查enabled，历史退出0不代替下面的协议/频段人工结论。

这组入口仍是工具级实现，未纳入默认启用模块，不改变已有6GHz或蓝牙模块。运行所需`reconnect.key`只在root私有任务目录内读取，禁止进入交付包。
